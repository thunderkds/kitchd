# Notice

A one-line outlined note with an icon: scope limits, caveats, a warning that needs reading.

- Info (`.gm-notice`): grey outline, info icon in `text-muted`. Replaces yellow callout boxes.
- Warning (`.gm-notice--warn`): amber outline and amber triangle icon; the text stays `text-2`, never amber.
- Use `role="note"`. Keep it to one or two sentences that say what is excluded or what to do.

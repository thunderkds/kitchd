# Button

A 40px action button: primary is the neon fill with a glow, secondary is an outline.

- Primary (`gm-btn gm-btn--primary`): one per section at most. Copy, View the source, the main call to action.
- Secondary (`gm-btn gm-btn--secondary`): everything else, including GitHub in the header.
- Small (`gm-btn--sm`): 36px, used for Copy inside a CodeBox.
- Use `<a>` for navigation and `<button type="button">` for actions. Text on primary is `on-neon`. Below 720px make the hit area 44px.

=== AC2: live recompute when Ingredient.cost_per_unit changes ===

$ (new org) POST /ingredients {"name":"Flour","costPerUnit":2}
$ POST /recipes {"name":"Bread","ingredients":[{"ingredientId":"<flour>","qty":1}]}
$ GET /recipes/:id -> costComputed: 2

$ PATCH /ingredients/:id {"costPerUnit":10}
$ GET /recipes/:id -> costComputed: 10
→ PASS. Recipe's cost reflects the NEW live ingredient price on next read, with no
  code change or recipe edit needed — confirms cost is never cached/stored.

=== AC3: editing a Recipe increments version, prior version data retrievable ===

$ PATCH /recipes/:id {"name":"Bread v3"}
$ GET /recipes/:id -> version: 3, name: "Bread v3"
$ GET /recipes/:id/versions ->
  v3: Bread v3
  v2: Bread v2

→ PASS. Version increments on each edit; full history retrievable via the append-only
  RecipeVersion table, oldest name ("Bread") still intact at v1.
